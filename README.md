# Skyline Excavations concept website

Concept website prepared for Skyline Excavations Pty Ltd (Sydney excavation, demolition and civil) by [Mago Labs](https://magolabs.in). Not the live site.

Static site: open `index.html`, or deploy the folder as-is on Vercel (no build step).

- `index.html`: the full page (styles and scripts inline)
- `assets/img`: job photos (WebP), logo files, favicon
- `assets/video`: muted site clips (MP4)
- `assets/fonts`: self-hosted EB Garamond, Jost and JetBrains Mono

A `noindex` meta tag in `index.html` keeps search engines out while this is a demo, without blocking link previews. Remove it when the site goes live.
